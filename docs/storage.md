# 儲存與備份

批註保存在目前網站的瀏覽器儲存空間，不會同步到維基帳戶或其他裝置。
桌面站與行動站、不同瀏覽器、不同使用者設定檔各自保存資料。
登出帳戶不會自動刪除同一瀏覽器中的批註。

## 瀏覽器資料

工具優先讀寫 `localStorage`。無法寫入時會嘗試 `sessionStorage`；
這種暫存通常只保留到瀏覽器分頁工作階段結束。
重新載入時若從 `sessionStorage` 讀到資料，會嘗試遷移回 `localStorage`。
兩者都無法寫入時，操作會回報失敗。

| 儲存鍵                                    | 內容                                                         |
| ----------------------------------------- | ------------------------------------------------------------ |
| `reviewtool:annotations:<pageName>`       | 該條目的批註、建立時間及最近一次清除的復原副本。             |
| `reviewtool:review-copied:<articleTitle>` | 是否已成功複製過該條目的評審文字，用來避免重複附加工具說明。 |

`pageName` 採用 MediaWiki 的頁面名稱；複製紀錄的 `articleTitle`
會把底線轉為空格。這些鍵沿用既有格式。
儲存空間受瀏覽器權限、配額與網站資料清理影響，請定期匯出備份。

## 匯出與匯入

在批註列表的「匯入／匯出」選單按「匯出」，下載包含下列欄位的 JSON：

| 欄位         | 說明                                                        |
| ------------ | ----------------------------------------------------------- |
| `pageName`   | 匯出時的條目名稱。                                          |
| `exportedAt` | 匯出時間，以 Unix 時間戳記的毫秒表示。                      |
| `groups`     | 依章節分組的批註；每組包含 `sectionPath` 與 `annotations`。 |

批註包含 ID、原文、意見、作者及建立時間，並可能包含編輯時間與文字定位資訊。
匯出檔包含評語及使用者名稱，分享前請先檢查內容。
匯出只備份目前的批註，不包含複製紀錄或清除復原副本。

在另一個瀏覽器開啟對應條目，載入工具後選擇「匯入」並選取 JSON。
匯入會寫入目前開啟的條目，並以 ID 去除重複項目；
不會依備份的 `pageName` 自動跳轉或寫入其他條目，也不會覆蓋已有的相同 ID。
請先核對所在條目。

匯入也接受直接含有 `annotations` 陣列的舊格式。
工具會先驗證整份備份，再修改儲存資料；
若任何批註的必要欄位或時間無效，整次匯入會失敗。
條目正文改動後，原文圖示可能無法重新定位，但批註仍可在列表查看及複製。

## 清除與復原

「清除全部」會把目前列表與它的復原副本一併寫入儲存空間。
若儲存失敗，原批註仍保留。
按「復原清除」會將副本合併回目前列表，略過相同 ID，然後移除該副本。
清除後新增的批註因此也能保留。

工具只保留最近一次成功清除的副本，後續清除會替換它。
刪除單則批註沒有同樣的復原功能，清理瀏覽器網站資料也會刪除副本。
長期保存或大幅整理前，請先匯出 JSON。
