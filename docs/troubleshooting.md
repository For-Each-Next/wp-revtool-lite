## 沒有「啟用批註模式」或「查看批註」

確認目前是中文維基百科條目頁，且已載入一種安裝檔案。
主控台載入方式在重新整理後需再執行一次；使用者指令碼則需確認管理器已啟用。
工具不會在討論頁或評審頁開啟批註介面。

在「更多」或「工具」中尋找選單，名稱及位置會隨外觀變化。
開啟瀏覽器主控台，查看 `[ReviewTool]` 開頭的錯誤，
確認 ResourceLoader、Vue 與 Codex 能正常載入。
介面文字依你的中文語言變體顯示；請在偏好設定中檢查語言。
安裝條件見[設定與執行環境](configuration.md)。

## 無法儲存或匯入批註

確認瀏覽器允許此網站使用本機儲存空間，且配額尚未用完。
隱私模式或限制儲存的瀏覽器設定可能只允許短暫保存，甚至完全拒絕寫入。
已有批註時請先嘗試匯出，再調整網站資料設定。

匯入檔應是工具匯出的 JSON，包含 `groups` 或 `annotations`。
必要欄位與時間必須有效；重複 ID 會略過，所以「沒有新的批註可匯入」
也可能表示備份已經匯入過。檔案詳情見[儲存與備份](storage.md)。

## 批註圖示不在原位置

條目修改後，原文或章節結構可能變動，工具未必能重新定位舊批註。
先開啟「查看批註」核對已保存的原文與意見。
列表與 JSON 備份不依賴圖示是否能定位。
需要針對新版正文評審時，先備份再重新建立相應批註。

## 無法複製或「複製並前往」沒有跳轉

複製評審文字需要取得目前顯示版本的時間。
先確認網路連線與瀏覽器剪貼簿權限，再按「複製」重試。
工具使用 Clipboard API；被拒絕時會顯示錯誤，請檢查權限後重試。
「複製並前往」只有在複製成功後才跳轉。

相關來源複製失敗時，編輯器會顯示可手動複製的文字。
若需要先保存工作，可使用 JSON 匯出，不必先完成評審文字複製。

## 回報問題

在[問題追蹤頁](https://github.com/For-Each-Next/wp-revtool-lite/issues)
提供瀏覽器、外觀、載入方式、工具版本、條目或版本連結、重現步驟及錯誤訊息。
若附上批註備份或截圖，先檢查是否含有不希望公開的評語或使用者資訊。
說明預期操作與實際結果，有助於製作可重現的離線測試。
